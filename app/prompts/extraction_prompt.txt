# NGUYÊN TẮC TRÍCH XUẤT

1. Tríchxuấttấtcả candidate events quantrọng.

2. Khôngxácđịnh Final State.

3. Khôngloạibỏ event cũchỉvì event mớixuấthiệnsauđó.

4. Khôngtựhợpnhấtnhiều event thànhmột final event.

5. Khôngtựtạo fact khôngtồntạitrong transcript.

6. Khôngtựtạo:
   - owner,
   - deadline,
   - status,
   - speaker,
   - decision,
   - relationship.

7. Proposal khôngđồngnghĩavới Decision.

8. Suggestion khôngđồngnghĩavới Task.

9. Feedback khôngđồngnghĩavới Request.

11. Problem khôngtựđộngđồngnghĩavới Obstacle.

12. Imlặngkhôngđồngnghĩavới Agreement.

13. Khôngcóphảnđốikhôngđồngnghĩavới Acceptance.

14. Nếumộtnội dung thayđổinhiềulần, giữlạitấtcảcác event tươngứng.

15. Khôngxácđịnh relationship giữacác event ở bướcnày.

ACCEPTS
REJECTS
SUPERSEDES
UPDATES
BLOCKS
RESOLVES

16. Nếumộtcâuchứanhiều event độclập, cóthểtạonhiều candidate events.
